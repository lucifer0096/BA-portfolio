## How to Navigate This Repo

1. Add each new business analytics project as its own top-level folder.
2. Read the project's own `README.md` for context, dataset details, assumptions, and approach.
3. Open the associated Excel / Power BI / Tableau / R / Python files to explore the analysis, dashboards, and apps.

## Skills Demonstrated

- **Business analysis:** requirements elicitation, KPI definition, stakeholder-focused reporting, process-oriented thinking
- **Data preparation:** business-data cleaning, multi-source joins, feature engineering, ETL-style pipelines, automated refresh workflows
- **Analysis:** segmentation, cohort analysis, parameter-driven scenarios, time-series, impact quantification, risk scoring
- **Visualization:** executive KPI dashboards, Excel slicers/heatmaps, R Shiny apps, Tableau dashboards (maps, parameters, actions), Power BI, Streamlit apps
- **Tooling:** Excel (pivot tables, slicers), SQL, Power BI, Tableau, Python (Pandas, Streamlit, LightGBM), R (Shiny), GitHub Actions
